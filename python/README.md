# worldguard (Python)

Python interface to the WorldGuard engine: Gymnasium-style environment, OpenAI-compatible LLM agent, held-out evaluation, SFT/DPO/RL dataset export and a GRPO reward function. Standard library only; the engine itself runs in Node.js 18+.

```bash
pip install -e python
python -m worldguard eval --model llama3.2
```

See the repository README and `docs/TRAINING_LLMS.md`.
